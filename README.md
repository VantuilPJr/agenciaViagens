# Voilà Voyages

**Website acadêmico de uma agência de viagens fictícia.**

Projeto desenvolvido para uma atividade de Experiência Criativa na PUCPR, com foco em estrutura de páginas, navegação, apresentação de destinos e construção de interfaces usando tecnologias web básicas.

**Stack:** HTML5 · CSS3 · JavaScript  
**Estado:** protótipo de interface; não realiza reservas ou pagamentos reais.

## O que o projeto apresenta

- Página inicial com apresentação de serviços e destinos.
- Navegação para pacotes em promoção e solicitação de orçamento.
- Organização visual com imagens, cards e identidade da agência fictícia.
- Estrutura estática para praticar HTML, estilos e interações no navegador.

## Visualizar localmente

```bash
git clone https://github.com/VantuilPJr/agenciaViagens.git
cd agenciaViagens/tarefaExperienciaCriativa
python -m http.server 8000
```

Abra [http://localhost:8000](http://localhost:8000). O comando usa somente o servidor estático da biblioteca padrão do Python; alternativamente, utilize um servidor estático de sua preferência.

## Estrutura

O conteúdo do site está em `tarefaExperienciaCriativa/`, incluindo `index.html`, páginas complementares, estilos e a pasta `image/`.

## Escopo

Este é um exercício de frontend. Os textos e elementos comerciais fazem parte da simulação de uma agência; não representam uma operadora real, disponibilidade de viagens ou uma integração com serviços de reserva.

## English summary

Voilà Voyages is an academic static website for a fictional travel agency, built with HTML, CSS and JavaScript at PUCPR. It presents destinations, promotional packages and a quotation interface. It is a frontend exercise and does not process real bookings or payments.
